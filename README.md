# VARENO — Premium E-Commerce Storefront

A full-featured e-commerce site with 22 products, cart, checkout, wishlist and search — backed by a real, working order pipeline.

## What it does
When a customer places an order, it's automatically:
1. Logged to Google Sheets
2. Confirmed via an automated email

No manual order handling, no paid automation platform — the whole pipeline runs on Google Apps Script.

## Stack
- HTML / CSS / JavaScript (frontend)
- Google Apps Script (backend logic)
- Google Sheets (order storage)
- Gmail API (automated confirmation emails)
- Netlify (hosting)
